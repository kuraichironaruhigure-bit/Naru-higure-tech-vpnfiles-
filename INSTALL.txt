NARU HIGURE FILE HUB — UPDATE PACKAGE

CONTENTS
- index.html: the current hub page, preserving its black/red design and existing sections.
- app.js: Supabase-powered file hub logic, country filtering/upload selection, community and feature tools.
- naru-higure-feature-upgrade.sql: additive database changes, including country column/index and admin role assignment.

INSTALL
1. Make a backup of the current GitHub repository before replacing files.
2. In the repository root, replace index.html with this package's index.html.
3. In the repository root, replace app.js with this package's app.js.
4. In Supabase Dashboard > SQL Editor, run naru-higure-feature-upgrade.sql.
5. Confirm the owner account kuraichironaruhigure@gmail.com already exists in Supabase Authentication before running the SQL admin-role update. After running it, sign out and sign in again so the refreshed JWT contains the admin role.
6. Confirm the Supabase project already has the original base tables (vpn_submissions, profiles, community_posts), the vpn-files storage bucket, and the original RPC functions record_file_view and record_file_download. This feature upgrade is additive and is not a replacement for the original base setup.
7. Commit the two website files to the repository root and wait for GitHub Pages to publish.
8. Open the site and hard-refresh/reload it. Test sign-in, file list, country filter, upload-country selector, and admin approval.

IMPORTANT
- This package does not contain or expose a Supabase service-role key.
- Country dropdown choices are populated locally by app.js; uploaded file country values are saved to the country column.
- Community messages older than 24 hours are filtered out by the current app code; this SQL does not schedule physical deletion.
- Some features depend on the base database schema, storage policies, and RPC functions already being correctly configured. A ZIP cannot verify your live Supabase policies or deploy to GitHub on your behalf.
- Back up the live site and database before applying updates.
